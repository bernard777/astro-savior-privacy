Politique de confidentialité d’Astro Savior

Version bêta Android (fr.astrosavior.beta). Dernière mise à jour le 16 novembre 2026.

Responsable et contact

Pour toute question sur vos données ou pour exercer vos droits, contactez l’éditeur d’Astro Savior à l’adresse ndongoambassa7@gmail.com.

Données enregistrées sur votre appareil

Le jeu ne demande pas de compte. Il enregistre localement votre progression, votre point de reprise, vos records, vos jetons et écussons ainsi que des compteurs d’utilisation de la bêta. Astro Savior n’envoie pas ces données à un serveur de l’éditeur et n’intègre pas de service d’analyse distinct. La sauvegarde et la dernière carte de défi générée restent dans l’espace privé de l’application. Pour les supprimer, effacez les données d’Astro Savior dans les paramètres Android ou désinstallez le jeu. Vous perdrez votre progression locale.

Publicité de test et choix de confidentialité

La bêta propose une vidéo de test facultative en fin d’opération. Elle peut rapporter un jeton cosmétique. L’application utilise Google Mobile Ads (AdMob) pour fournir la vidéo et Google User Messaging Platform pour actualiser vos choix de confidentialité et afficher les écrans de consentement lorsqu’ils sont requis. Ces services de Google peuvent recevoir votre adresse IP, qui permet d’estimer votre localisation approximative, des informations sur les interactions, des diagnostics de fonctionnement ainsi que des identifiants de l’appareil ou du compte, dont l’identifiant publicitaire lorsqu’il est disponible. Google peut utiliser ces informations pour la publicité, les mesures et la prévention de la fraude. Le SDK publicitaire transmet ses données via des connexions chiffrées. Lorsque Google rend ce réglage disponible, vous pouvez modifier vos choix depuis « Choix de confidentialité » à l’accueil.

Invitations et partage

Si vous arrivez depuis une invitation, Astro Savior peut lire, via Google Play Install Referrer, le paramètre d’installation qui contient le code du défi. Le jeu traite ce code sur l’appareil pour ouvrir la bonne opération. Lorsque vous choisissez « Défier un ami », le jeu prépare un texte et une image avec le score, le nombre de capsules sauvées, le chrono et le code. Ces éléments peuvent être transmis à l’application de partage et aux destinataires que vous choisissez. Leur conservation dépend ensuite du service utilisé et des destinataires. Vous pouvez aussi saisir un code dans le jeu sans utiliser le lien d’installation.

Conservation et demandes

Les fichiers locaux restent sur votre appareil jusqu’à leur remplacement ou leur suppression. Les données traitées par Google sont conservées selon ses propres règles. Si vous contactez l’éditeur, il utilise votre adresse et le contenu de votre message pour traiter la demande. Ces échanges sont conservés le temps nécessaire à son traitement et au suivi, sauf obligation de conservation. Vous pouvez contacter l’éditeur pour demander l’accès, la rectification ou la suppression de vos données, leur portabilité ou la limitation du traitement, ou pour vous y opposer, selon les droits applicables.
